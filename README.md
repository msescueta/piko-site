# piko-site

Public support and privacy pages for **PIKO – The Pinoy Game**, served by GitHub Pages:

- Support: https://msescueta.github.io/piko-site/
- Privacy Policy: https://msescueta.github.io/piko-site/privacy/

The privacy policy source is `docs/privacy-policy.md` in the (private) app repo.
To update: copy it to `privacy-policy.md` here, run `python3 build.py`, commit and push.
